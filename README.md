# Student Attendance Tracker

## 📌 Project Overview
This project is a web-based **Student Attendance Tracker** application built as part of the Naan Mudhalvan skill training program. It provides an interactive dashboard for educational institutions to manage student databases, track daily attendance records, and evaluate attendance percentages against defined thresholds.

## ✨ Key Features
- **Student Record Management:** Add, update, and delete student data dynamically with unique IDs and departmental sorting.
- **Daily Attendance Logging:** Mark students with status options including *Present*, *Absent*, *Late*, or *Leave* for any selected calendar date.
- **Threshold Warnings:** Automatically calculates overall percentages and highlights students falling below the minimum threshold (default: 75%).
- **Advanced Search & Filtering:** Filter student rows instantly by status or search records using names, IDs, or departments.
- **Persistent Data:** Utilizes browser `LocalStorage` to ensure data persistence across sessions.

## 🛠️ Technologies Used
- **HTML5:** Semantic markup and document layout.
- **CSS3:** Responsive styling, interface design, and custom status badges.
- **JavaScript (ES6+):** Dynamic event handling, date management, and state logic.

## 🚀 How to Run Locally
1. Clone or download this repository to your local machine.
2. Ensure `index.html`, `style.css`, and `script.js` are in the same folder directory.
3. Double-click `index.html` to open and run the application directly in any modern web browser.
